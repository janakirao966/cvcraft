# CVCraft — Professional Resume Architect

A high-performance, client-side, browser-native ATS-compliant resume builder and multi-document assembler.

![CVCraft Banner](logo.png)

## 🚀 Key Features

* **Universal ATS-Ready A4 Engine**: Pixel-perfect multi-page A4 typography, proportional 120x120 photo framing, and crisp printable layout.
* **Comprehensive 6-Step Profile Wizard**: Guided setup for contact details, objective, technical & academic qualifications, structured work history, key competencies, personal data, and passport verification.
* **5-Slot Preset Switcher**: Easily save, swap, and manage multiple resume configurations (e.g. Piping Foreman vs Fabricator) with a single click.
* **Instant Certificate & Document Merging**: Attach trade certificates, diplomas, passport scans, and multi-page PDFs directly to your generated resume.
* **100% Client-Side Privacy**: Stored securely in your browser's IndexedDB and localStorage — zero external server uploads.
* **Full-Fidelity JSON Backup & Restore**: Export and import complete resume states and attachments via drag-and-drop or file upload.
* **Intelligent Session Routing**: Opens the modern landing page on first launch and automatically resumes your active workspace on return visits.

---

## 🛠️ Getting Started

CVCraft requires **no build step**, **no server dependencies**, and **no package managers**.

Simply clone the repository and open `index.html` in any modern browser:

```bash
git clone https://github.com/janakirao966/cvcraft.git
cd cvcraft
```

Open `index.html` or `CVCraft.html` directly in your browser.
